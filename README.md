# 🚀 CareerForge Pro

A full-stack AI-powered resume builder with ATS scoring and PDF export.

## 🔥 Features
- Resume Builder
- ATS Score Analyzer
- AI Resume Rewriter
- PDF Download (Puppeteer)
- Stripe Subscription (Free vs Pro)

## 🛠 Tech Stack
- React.js
- Node.js + Express
- Tailwind CSS
- OpenAI API
- Puppeteer
- Stripe

## 🚀 How to Run

### Frontend
cd client
npm install
npm start

### Backend
cd server
npm install
node index.js

### Free:
- Resume Builder
