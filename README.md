# 🚀 CareerForge Pro

An AI-powered full-stack resume builder with ATS scoring, AI rewriting, PDF export, and Pro feature system.

---

## 🔥 Features

### 🟢 Week 1: Builder Core
- Resume Builder (Form + Live Preview)
- React State Management

### 🔵 Week 2: AI + ATS
- Job Description Parsing
- Keyword Extraction
- ATS Score Calculation
- AI Resume Bullet Rewriting

### 🟣 Week 3: PDF + Payments
- PDF Export (Puppeteer)
- Stripe Subscription Integration
- Free vs Pro Access Control

### 🟡 Week 4: Final Polish
- Dashboard-style UI (cards, layout, animations)
- Improved ATS logic (noise filtering, better keyword handling)
- Cover Letter Generator (AI-based)
- UI/UX Enhancements (Tailwind styling, responsiveness)

---

## 🛠 Tech Stack

- Frontend: React.js + Tailwind CSS
- Backend: Node.js + Express
- AI: OpenAI API
- PDF: Puppeteer
- Payments: Stripe

---

## 🚀 How to Run

### 1️⃣ Clone the repo
```
git clone https://github.com/eshita2311/careerforge-pro.git
```

---

### 2️⃣ Backend Setup
```
cd server
npm install
node index.js
```

---

### 3️⃣ Frontend Setup
```
cd client
npm install
npm start
```

---

## 🔑 Environment Variables

Create `.env` inside `/server`:

```
OPENAI_API_KEY=your_key_here
STRIPE_SECRET_KEY=your_key_here
```
